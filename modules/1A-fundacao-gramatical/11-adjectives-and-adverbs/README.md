# 11 — Adjetivos e advérbios: ordem e posição

> Adjetivo em inglês vem **antes** do substantivo e **nunca** vai pro plural.
> E existe o par que mais constrange brasileiro em reunião: *"I'm boring"*
> não quer dizer o que você acha que quer dizer.

**Módulo:** 1A · **Sessões:** 2 · **Anterior:** [10 — Modais básicos](../10-basic-modals/) · **Próxima:** [12 — Comparativos e superlativos](../12-comparatives-superlatives/)

---

## 1. A ideia em uma frase

Adjetivo **antes** do substantivo, invariável; advérbio tem **posição fixa** conforme
o tipo.

---

## 2. Forma

### Adjetivo — invariável e antes do substantivo

```
✅ a red car          ❌ a car red        (ordem)
✅ red cars           ❌ reds cars        (adjetivo não pluraliza)
✅ two big problems   ❌ two bigs problems
```

**Depois de verbo de ligação** (`be`, `seem`, `look`, `feel`, `sound`, `become`):

```
The API is slow.
This looks wrong.
It sounds good.
```

### Ordem de vários adjetivos — **OSASCOMP**

Quando você empilha adjetivos, a ordem é fixa:

| Opinion | Size | Age | Shape | Color | Origin | Material | Purpose |
|---------|------|-----|-------|-------|--------|----------|---------|
| nice | big | old | round | black | Brazilian | wooden | racing |

```
a nice big old wooden table
a beautiful small black Japanese knife
an ugly legacy Python script
```

> 💡 Você **não precisa decorar isso**. Nativo também não sabe a regra — só sente.
> Na prática, **raramente use mais de 2 adjetivos**. Se precisou de 4, reescreva a frase.

### Advérbio — formação

| Regra | Exemplo |
|-------|---------|
| adjetivo + `-ly` | quick → quick**ly** · careful → careful**ly** |
| `-y` → `-ily` | easy → eas**ily** · happy → happ**ily** |
| `-le` → `-ly` | simple → simp**ly** · possible → possib**ly** |
| `-ic` → `-ically` | automatic → automat**ically** · basic → bas**ically** |

**Irregulares — os que importam:**

| Adjetivo | Advérbio | Cuidado |
|----------|----------|---------|
| good | **well** | *~~He speaks good~~* → He speaks **well** |
| fast | **fast** | não existe *~~fastly~~* |
| hard | **hard** | `hardly` = **quase não** (outra palavra!) |
| late | **late** | `lately` = ultimamente |
| early | **early** | — |

```
He works hard.        ← ele trabalha muito
He hardly works.      ← ele quase não trabalha    ⚠️ oposto!
```

## 3. Uso — posição do advérbio

### 3.1 Advérbios de frequência — **antes** do verbo principal, **depois** do `be`

`always · usually · often · sometimes · rarely · never`

```
✅ I always check the logs.          ❌ I check always the logs.
✅ She never replies on Slack.       ❌ She replies never
✅ He is always late.                ← depois do "be"
✅ I have never seen this error.     ← entre auxiliar e verbo
```

> 🇧🇷 Português coloca depois do verbo (*"Eu verifico **sempre**"*). Inglês, antes.
> Este é o erro de ordem mais frequente do módulo.

### 3.2 Advérbios de modo — depois do verbo ou do objeto

```
✅ She explained it clearly.
✅ He handled the incident well.
❌ She explained clearly it.          ← nunca entre verbo e objeto
```

### 3.3 Advérbios de tempo e lugar — início ou fim

```
Yesterday I fixed three bugs.
I fixed three bugs yesterday.
We deploy on Fridays.
```

### 3.4 🔴 `-ed` vs `-ing` — o par que muda o sentido

| `-ing` = **o que causa** | `-ed` = **como eu me sinto** |
|--------------------------|------------------------------|
| The meeting is **boring**. | I'm **bored**. |
| This bug is **confusing**. | I'm **confused**. |
| The result was **surprising**. | I was **surprised**. |
| The task is **frustrating**. | I'm **frustrated**. |
| It's **interesting**. | I'm **interested**. |
| The news is **exciting**. | I'm **excited**. |
| The process is **tiring**. | I'm **tired**. |

```
❌ I'm boring.        → "Eu sou uma pessoa chata."     😬
✅ I'm bored.         → "Estou entediado."

❌ I'm confusing.     → "Eu confundo os outros."
✅ I'm confused.      → "Estou confuso."
```

> **Regra de bolso:** pessoa quase sempre leva `-ed`. Coisa quase sempre leva `-ing`.

## 4. 🇧🇷 Erros de brasileiro

| ❌ | ✅ | Por quê |
|----|----|---------|
| *a solution simple* | a **simple solution** | Adjetivo vem antes |
| *reds errors* | **red** errors | Adjetivo não pluraliza |
| *I check always the logs.* | I **always check** the logs. | Frequência vem antes do verbo |
| *He speaks good English.* ✅ / *He speaks good.* | He speaks **well**. | `good` é adjetivo, `well` é advérbio |
| *He works hardly.* | He works **hard**. | `hardly` = quase não |
| *I'm boring.* | I'm **bored**. | `-ing` = causa, `-ed` = sentimento |
| *This is very confused.* | This is **confusing**. | A coisa causa confusão |
| *She explained clearly the issue.* | She explained the issue **clearly**. | Advérbio não separa verbo de objeto |
| *He drives very fastly.* | very **fast** | `fast` não tem forma `-ly` |
| *I'm interesting in this role.* | I'm **interested** in this role. | Erro comum em entrevista 😬 |
