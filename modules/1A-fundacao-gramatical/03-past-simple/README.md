# 03 — Past Simple

> O tempo que você mais vai usar numa daily: *"Yesterday I fixed…"*. E o lugar do
> erro mais persistente de todos: **`didn't went`**.

**Módulo:** 1A · **Sessões:** 2 · **Anterior:** [02 — Present Simple vs Continuous](../02-present-simple-vs-continuous/) · **Próxima:** [04 — Artigos](../04-articles/)

---

## 1. A ideia em uma frase

Ação **terminada** num momento **terminado** do passado — com ou sem a data dita.

---

## 2. Forma

### Afirmativo — verbo no passado

| Regular | Irregular |
|---------|-----------|
| I **worked** · she **deployed** · we **tested** | I **went** · she **wrote** · we **broke** |

**Ortografia do `-ed`:**

| Regra | Exemplo |
|-------|---------|
| padrão | work → work**ed** |
| termina em `-e`: só `+d` | close → close**d** |
| consoante + `y` → `ied` | try → tr**ied** *(vogal+y: deploy → deployed)* |
| 1 sílaba CVC: dobra | stop → sto**pp**ed · plan → pla**nn**ed |

### Negativo e pergunta — `did` + **verbo no infinitivo**

| | Exemplo |
|---|---------|
| Negativo | I **didn't finish** the task. |
| Pergunta | **Did** you **deploy** it? |
| Wh- | What **did** he **say**? |

> 🔴 **A regra mais importante desta aula:**
> `did` **já carrega o passado**. O verbo depois dele volta ao infinitivo.
> *I didn't **go*** — nunca *~~didn't went~~*.
> Vale para `did`, `didn't` e perguntas com `did`.

### `to be` no passado — não usa `did`

| | |
|---|---|
| I / he / she / it | **was** · **wasn't** · **Was** he…? |
| you / we / they | **were** · **weren't** · **Were** they…? |

*I **was** in a meeting.* · ***Were** you there?* — nunca *~~Did you were~~*.

### Pronúncia do `-ed` — 3 sons, não 3 sílabas

| Som | Quando | Exemplos |
|-----|--------|----------|
| /t/ | após som surdo (p, k, f, s, sh, ch, x) | wor**ked** · pu**shed** · fi**xed** |
| /d/ | após som sonoro (b, g, v, m, n, l, r, vogais) | clos**ed** · plann**ed** · tri**ed** |
| /ɪd/ | **só** após `t` ou `d` | want**ed** · need**ed** · start**ed** |

> 🇧🇷 Brasileiro tende a pronunciar tudo como `/ɪd/` — *"work-ed-i"*. Só `t` e `d`
> ganham sílaba extra. `worked` tem **uma** sílaba.

## 3. Uso

### 3.1 Os casos

| Uso | Exemplo |
|-----|---------|
| Ação terminada com tempo definido | I **fixed** it **yesterday**. |
| Sequência de ações | I **opened** the PR, **ran** the tests and **merged** it. |
| Estado passado | The build **was** broken all morning. |
| Hábito passado (que acabou) | We **used to deploy** manually. / We **deployed** manually back then. |

### 3.2 Marcadores que exigem Past Simple

`yesterday · last week/month/year · in 2020 · two days ago · then · when I was…`

> Se a frase tem um destes, **é Past Simple**, não Present Perfect.
> *~~I have deployed it yesterday~~* → **I deployed it yesterday.**

### 3.3 Irregulares que você usa toda semana

| Base | Passado | | Base | Passado |
|------|---------|---|------|---------|
| be | was / were | | make | made |
| have | had | | take | took |
| do | did | | get | got |
| go | went | | give | gave |
| say | said | | find | found |
| write | wrote | | think | thought |
| read | read *(pron. "red")* | | run | ran |
| break | broke | | build | built |
| send | sent | | leave | left |
| begin | began | | come | came |
| see | saw | | know | knew |
| put | put | | set | set |

> Aprenda em **frases**, não em lista. *"I broke the build"* gruda; `break-broke-broken` solto, não.

## 4. 🇧🇷 Erros de brasileiro

| ❌ | ✅ | Por quê |
|----|----|---------|
| *I didn't went.* | I didn't **go**. | `did` já marca o passado |
| *Did you finished?* | Did you **finish**? | Idem, na pergunta |
| *Did you were there?* | **Were** you there? | `to be` não usa `did` |
| *I have deployed it yesterday.* | I **deployed** it yesterday. | Marcador de tempo definido → Past Simple |
| *He readed the docs.* | He **read** the docs. | Irregular |
| *I was go to the office.* | I **went** to the office. | Só um verbo carrega o tempo |
| *work-ed-i* (3 sílabas) | /wɜːrkt/ (1 sílaba) | `-ed` só vira sílaba após `t`/`d` |
| *When I arrived, he was leave.* | …he **was leaving** / he **left**. | Forma incompleta |

## 5. ✍️ Prática

**A. Traduza (10).**
1. Eu consertei o bug ontem.
2. Ela não terminou a task.
3. Você fez deploy na sexta?
4. Nós quebramos o build sem querer.
5. O que ele disse na reunião?
6. Eu não fui à daily porque estava numa call.
7. Eles não estavam disponíveis.
8. Eu li a documentação e escrevi os testes.
9. Você estava no escritório ontem?
10. Eu tentei três abordagens diferentes e nenhuma funcionou.

**B. Escreva a sua daily de ontem** — 6 linhas, tudo no Past Simple, com pelo menos
4 verbos irregulares.

**C. Leia o exercício B em voz alta e grave.** Ouça: você está pronunciando `-ed` como
sílaba extra onde não devia?
