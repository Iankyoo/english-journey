# 12 — Comparativos e superlativos

> Última aula do módulo. Você compara coisas o dia inteiro no trabalho — abordagens,
> performance, trade-offs. E *"more better"* é o erro que mais rápido revela A2.

**Módulo:** 1A · **Sessões:** 1 · **Anterior:** [11 — Adjetivos e advérbios](../11-adjectives-and-adverbs/) · **Próxima:** ✅ [Fechar o Módulo 1A](../)

---

## 1. A ideia em uma frase

Adjetivo **curto** ganha terminação (`-er`/`-est`); adjetivo **longo** ganha palavra
(`more`/`most`) — e **nunca os dois**.

---

## 2. Forma

### A regra por tamanho

| Tamanho | Comparativo | Superlativo | Exemplo |
|---------|-------------|-------------|---------|
| **1 sílaba** | `-er` | `the -est` | fast → fast**er** → **the** fast**est** |
| **2 sílabas terminadas em `-y`** | `-ier` | `the -iest` | easy → eas**ier** → **the** eas**iest** |
| **2 sílabas (outras)** | `more` | `the most` | modern → **more** modern → **the most** modern |
| **3+ sílabas** | `more` | `the most` | efficient → **more** efficient → **the most** efficient |

**Ortografia:**

| Regra | Exemplo |
|-------|---------|
| `-e` final: só `+r` / `+st` | simple → simpler → the simplest |
| CVC 1 sílaba: dobra | big → bi**gg**er · hot → ho**tt**er |
| consoante + `y` → `ier` | busy → busier · easy → easier |

### Irregulares — obrigatórios

| Adjetivo | Comparativo | Superlativo |
|----------|-------------|-------------|
| good / well | **better** | **the best** |
| bad / badly | **worse** | **the worst** |
| far | **further** / farther | **the furthest** / farthest |
| little | **less** | **the least** |
| much / many | **more** | **the most** |

> ⚠️ `worse` (pior) ≠ `worst` (o pior). *"It got **worse**"* · *"the **worst** outage"*.

### As estruturas

| Estrutura | Uso | Exemplo |
|-----------|-----|---------|
| `X + comparativo + **than** + Y` | comparação | Redis is fast**er than** Postgres for this. |
| `**as** + adjetivo + **as**` | igualdade | This is **as fast as** the old version. |
| `**not as** + adj + **as**` | inferioridade | It's **not as complex as** it looks. |
| `**the** + superlativo` | o extremo | This is **the worst** approach. |
| `**the same as**` | igualdade | The result is **the same as** before. |
| `**different from**` | diferença | This is **different from** what we discussed. |
| `**twice/three times as** + adj + **as**` | múltiplos | It's **twice as fast as** before. |
| `**the** + comp + `,` + **the** + comp` | proporção | **The more** tests, **the safer** the refactor. |

---

## 3. Uso — comparando no trabalho

```
This approach is simpler and easier to maintain.
Postgres is more reliable than what we're using now.
The new endpoint is twice as fast as the old one.
This is the worst possible time to deploy.
Rewriting is less risky than patching it again.
It's not as bad as it looks.
The more context you give me, the faster I can help.
This solution is far better than the alternative.       ← "far" intensifica
It's slightly slower, but much more readable.
```

**Intensificadores de comparativo** — mudam a força:

| Fraco → Forte | |
|---------------|---|
| **slightly** faster | um pouco |
| **a bit** faster | um pouco |
| **much / far / a lot** faster | muito |
| **significantly** faster | significativamente |

> *~~very faster~~* ❌ — `very` **não** modifica comparativo. Use **`much`** ou **`far`**.

---

## 4. 🇧🇷 Erros de brasileiro

| ❌ | ✅ | Por quê |
|----|----|---------|
| *more better* | **better** | Comparativo duplo — nunca os dois |
| *more easy* | **easier** | 2 sílabas com `-y` usa `-ier` |
| *the more good solution* | **the best** solution | Irregular |
| *This is bigger that the other.* | bigger **than** | `than` (comparação) ≠ `that` (que) |
| *as fast than* | as fast **as** | Estrutura `as…as` |
| *the same than* | the same **as** | Bloco fixo |
| *different than* ⚠️ | different **from** | `than` aceito nos EUA, mas `from` é o seguro |
| *very faster* | **much** faster | `very` não intensifica comparativo |
| *It's more worse.* | It's **worse**. | Duplo |
| *twice more fast* | **twice as fast as** | Estrutura fixa |
| *He is the most fast.* | He is **the fastest**. | 1 sílaba usa `-est` |

> 🎯 O par `than`/`that` é sonoro: brasileiro ouve os dois como "dét". Treine em voz alta —
> `than` /ðæn/ com vogal aberta, `that` /ðæt/ terminando em `t`.

## 5. ✍️ Prática

**A. Traduza (10).**
1. Essa abordagem é mais simples que a anterior.
2. Redis é mais rápido que Postgres para cache.
3. Esse é o pior bug que já vi.
4. A nova versão é duas vezes mais rápida que a antiga.
5. Não é tão complexo quanto parece.
6. O resultado é o mesmo de antes.
7. Reescrever é menos arriscado que corrigir de novo.
8. Quanto mais testes, mais seguro o refactor.
9. Essa solução é muito melhor que a alternativa.
10. É um pouco mais lento, mas bem mais legível.

**B. Compare 5 pares de tecnologias** que você usa (ex.: REST vs GraphQL, SQL vs NoSQL).
Uma frase com `-er/than`, uma com `more/than`, uma com `as…as`, uma com `not as…as`,
uma com superlativo.

**C. Escreva um parágrafo de 8 linhas** justificando uma decisão técnica — comparando
duas opções. Use pelo menos 4 comparativos e 1 superlativo.
