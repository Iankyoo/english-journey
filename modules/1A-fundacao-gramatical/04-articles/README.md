# 04 — Artigos: a / an / the / zero

> A aula com maior retorno do módulo. Artigo é o erro que **mais aparece** em texto de
> brasileiro e o que **menos é corrigido** — porque não impede o entendimento, só
> marca o texto como estrangeiro em toda linha.

**Módulo:** 1A · **Sessões:** 2 · **Anterior:** [03 — Past Simple](../03-past-simple/) · **Próxima:** [05 — Contáveis e incontáveis](../05-countable-uncountable/)

---

## 1. A ideia em uma frase

`a/an` = **um entre vários** · `the` = **aquele específico que nós dois sabemos qual é** ·
**zero** = **a categoria inteira, em geral**.

---

## 2. Forma

### `a` vs `an` — decide pelo **som**, não pela letra

| `a` + som de consoante | `an` + som de vogal |
|------------------------|---------------------|
| **a** bug | **an** error |
| **a** user | **an** hour *(h mudo → som /aʊ/)* |
| **a** university *(som /juː/)* | **an** MVP *(lê-se "em-vi-pi")* |
| **a** URL *(som /juː/)* | **an** SQL query *(lê-se "és-ki-el")* |
| **a** one-liner *(som /w/)* | **an** honest answer |

> 🎯 Truque: **fale a palavra em voz alta**. Se a boca começa com vogal, é `an`.
> Siglas seguem como você **lê**, não como se escreve.

---

## 3. Uso

### 3.1 `a / an` — primeira menção, um entre muitos

```
I found a bug.              ← você ainda não sabe qual
She's a developer.          ← profissão SEMPRE leva artigo no singular
We need a new approach.
It took an hour.
```

> 🔴 **Substantivo contável no singular nunca fica sozinho.** Precisa de `a`, `the`,
> `my`, `this`… *~~I'm developer~~* está tão errado quanto *~~I'm the developer~~* seria impreciso.

### 3.2 `the` — específico, único ou já mencionado

| Caso | Exemplo |
|------|---------|
| Já mencionado | I found a bug. **The** bug is in auth. |
| Único no contexto | **The** build is broken. · **The** CTO approved it. |
| Único no mundo | **the** sun · **the** internet · **the** same |
| Superlativo e ordinal | **the** best solution · **the** first commit |
| Especificado por complemento | **the** name of the file · **the** file I sent you |

### 3.3 Zero article — a categoria em geral

Esta é a que o português quebra. Em português, generalização **leva** artigo:
*"**A** vida é difícil"*. Em inglês, **não**.

| Categoria | ✅ Inglês | ❌ Erro típico |
|-----------|----------|---------------|
| Plural genérico | **Developers** love coffee. | *~~The developers~~* (a não ser que sejam específicos) |
| Incontável genérico | **Life** is hard. · **Software** is expensive. | *~~The life~~* · *~~The software~~* |
| Idiomas | I speak **English**. | *~~the English~~* |
| Refeições | before **lunch** | *~~the lunch~~* |
| Maioria dos países / cidades | **Brazil**, **São Paulo** | *~~The Brazil~~* |
| Esportes / matérias | I play **football**. I study **math**. | *~~the football~~* |
| Empresas / linguagens | at **Google** · in **Python** | *~~the Google~~* |
| Next/last + tempo | **next** week · **last** year | *~~the next week~~* |
| Institucional (função) | go to **work**, **school**, **bed**, **home** | *~~to the work~~* |

> **Exceção de países:** leva `the` quando o nome é plural ou tem substantivo comum —
> **the** United States, **the** Netherlands, **the** UK, **the** Philippines.

### 3.4 O contraste que resolve 80% dos casos

```
I like dogs.              ← cachorros em geral (categoria)
I like the dogs.          ← aqueles cachorros específicos ali

Coffee is expensive.      ← café, a bebida, em geral
The coffee is cold.       ← este café aqui

She's at school.          ← estudando (função da instituição)
She's at the school.      ← no prédio, fisicamente
```

## 4. 🇧🇷 Erros de brasileiro

| ❌ | ✅ | Por quê |
|----|----|---------|
| *The life is hard.* | **Life** is hard. | Generalização não leva artigo |
| *I like the dogs.* | I like **dogs**. | Categoria, não indivíduos |
| *I'm developer.* | I'm **a** developer. | Profissão no singular pede artigo |
| *I speak the English.* | I speak **English**. | Idiomas não levam artigo |
| *The Brazil is big.* | **Brazil** is big. | País no singular sem artigo |
| *In the next week.* | **Next** week. | `next/last` já especificam |
| *The most of developers.* | **Most** developers. | `most` genérico dispensa `the` |
| *I go to the work.* | I go to **work**. | Uso institucional |
| *A information.* | **Some information** / **a piece of** information | Incontável → [aula 05](../05-countable-uncountable/) |
| *An user.* | **A** user. | `user` começa com som /juː/ = consoante |
| *A hour.* | **An** hour. | `h` mudo → som de vogal |

## 5. ✍️ Prática

**A. Preencha com `a`, `an`, `the` ou `—` (zero). Escreva a frase inteira (12).**
1. I'm ___ backend developer at ___ startup.
2. ___ life of ___ developer is full of ___ meetings.
3. I found ___ bug. ___ bug is in ___ payment service.
4. She speaks ___ English and ___ Portuguese.
5. It took ___ hour and ___ half.
6. We're migrating to ___ AWS next ___ month.
7. ___ documentation you sent me was ___ best I've read.
8. ___ developers usually prefer ___ dark mode.
9. He works at ___ Google, in ___ United States.
10. I go to ___ work by ___ bus.
11. This is ___ URL, not ___ endpoint.
12. ___ software is eating ___ world.

**B. Escreva 5 frases generalizando** sobre a sua área (ex.: sobre devs, sobre código,
sobre reuniões). Nenhuma pode ter `the`.

**C. Pegue um daily log seu já escrito** e marque **todo** substantivo. Para cada um,
pergunte: é específico (`the`), um entre vários (`a/an`) ou uma categoria (zero)?

---

## 6. ✅ Critério de conclusão

- [ ] Acertar 10+ das 12 do exercício A
- [ ] Explicar em voz alta, com exemplo próprio, a diferença entre `I like dogs` e `I like the dogs`
- [ ] Escrever 5 generalizações seguidas sem usar `the` nenhuma vez
- [ ] Decidir `a` vs `an` corretamente em: *user, hour, MVP, URL, honest, university, SQL, one-off*
- [ ] Nunca mais escrever *"I'm developer"* nem *"The life is…"*

**Teste final:** o exercício C aplicado a um texto de 150 palavras seu. Se você errou
mais de 3 artigos, refaça a aula — este é o item que mais custa em correção de redação
de certificação.
