# 06 — Quantificadores

> `some`/`any`, `much`/`many`, `a few`/`a little`. Aqui um artigo de uma letra muda
> o sentido de "alguns" para "quase nenhum" — e isso já custou promoção a gente.

**Módulo:** 1A · **Sessões:** 1 · **Anterior:** [05 — Contáveis e incontáveis](../05-countable-uncountable/) · **Próxima:** [07 — Pronomes](../07-pronouns/)

---

## 1. A ideia em uma frase

Quantificador se escolhe por **duas perguntas**: o substantivo é contável? a frase é
afirmativa, negativa ou pergunta?

---

## 2. Forma

| | Contável (plural) | Incontável | Ambos |
|---|------------------|------------|-------|
| Muito | **many** bugs | **much** time | **a lot of** / **lots of** |
| Pouco (positivo) | **a few** bugs | **a little** time | — |
| Pouco (negativo) | **few** bugs | **little** time | — |
| Algum | — | — | **some** / **any** |
| Nenhum | — | — | **no** / **none** |
| Suficiente | — | — | **enough** |

---

## 3. Uso

### 3.1 `some` vs `any`

| | Regra | Exemplo |
|---|-------|---------|
| **some** | afirmativa | I have **some** questions. |
| **any** | negativa | I don't have **any** questions. |
| **any** | pergunta | Do you have **any** questions? |
| **some** | oferta / pedido *(espera "sim")* | Would you like **some** coffee?<br>Could you send me **some** examples? |
| **any** | afirmativa = "qualquer um" | **Any** approach works. Pick **any** file. |

### 3.2 `much` / `many` / `a lot of`

```
How many open bugs do we have?        ← contável, pergunta
How much time do we have?             ← incontável, pergunta
We don't have much time.              ← incontável, negativa
There are a lot of edge cases.        ← afirmativa — prefira "a lot of"
```

> 🎯 **Regra prática de registro:** em **afirmativas**, `much` e `many` soam formais ou
> estranhos em fala. Use **`a lot of`**.
> *"We have a lot of tests"* ✅ soa natural · *"We have many tests"* ⚠️ soa de livro.
> Em **negativas e perguntas**, `much`/`many` são o normal.

### 3.3 `a few` vs `few` — o artigo muda tudo

Este é o item mais importante da aula.

| | Sentido | Exemplo |
|---|---------|---------|
| **a few** + contável | *alguns* — quantidade pequena, mas **positiva** | I have **a few** ideas. → tenho ideias ✅ |
| **few** + contável | *poucos* — quase nenhum, **negativo** | I have **few** ideas. → estou sem ideias ⚠️ |
| **a little** + incontável | *um pouco* — **positivo** | We have **a little** time. → dá pra fazer ✅ |
| **little** + incontável | *pouco* — **negativo** | We have **little** time. → não vai dar ⚠️ |

```
A few developers reviewed it.     ← alguns revisaram (bom)
Few developers reviewed it.       ← quase ninguém revisou (reclamação)

I need a little help.             ← me dá uma ajudinha
I got little help.                ← fui abandonado
```

> Na dúvida em contexto profissional, use **`a few` / `a little`**. Sem o artigo,
> você está fazendo uma crítica — e talvez sem querer.

### 3.4 `no` / `none` / `enough`

```
There are no blockers.            ← "no" + substantivo
How many are left? None.          ← "none" sozinho, sem substantivo
We don't have enough context.     ← enough VEM ANTES do substantivo
This isn't good enough.           ← mas DEPOIS do adjetivo
```

> ⚠️ `enough` muda de lado: **antes** de substantivo (`enough time`), **depois** de
> adjetivo (`fast enough`, `clear enough`).

## 4. 🇧🇷 Erros de brasileiro

| ❌ | ✅ | Por quê |
|----|----|---------|
| *I don't have some time.* | I don't have **any** time. | Negativa pede `any` |
| *Do you have some questions?* | Do you have **any** questions? | Pergunta neutra pede `any` |
| *Much people came.* | **Many** people came. / A lot of people | `people` é contável |
| *How much bugs?* | How **many** bugs? | Contável |
| *I have few time.* | I have **little** time. | `time` é incontável |
| *I have few ideas* (querendo dizer "algumas") | I have **a few** ideas. | Sem `a`, vira crítica |
| *We have enough not context.* | We **don't** have **enough** context. | Posição |
| *It's not enough fast.* | It's not **fast enough**. | Depois do adjetivo |
| *Any of them worked* (querendo "nenhum") | **None** of them worked. | `any` afirmativo = "qualquer um" |

## 5. ✍️ Prática

**A. Complete e escreva a frase inteira (10).**
1. Do we have ___ (some/any) blockers today?
2. I don't have ___ (much/many) context on this.
3. There are ___ (a lot of / much) edge cases here.
4. How ___ (much/many) time do you need?
5. I have ___ (a few / few) suggestions — nothing major. *(sentido positivo)*
6. ___ (A few / Few) people showed up to the retro. *(reclamação)*
7. Could you send me ___ (some/any) examples?
8. We have ___ (a little / little) time before the deadline. *(dá pra fazer)*
9. This solution isn't ___ (enough robust / robust enough).
10. How many tests failed? ___ (None / Any).

**B. Escreva 6 frases sobre o estado atual do seu projeto** usando: `some`, `any`,
`a lot of`, `a few`, `much`, `enough`.

**C. Escreva duas versões da mesma frase** — uma com `a few` e outra com `few` — e explique
em português como o sentido muda para quem lê.
