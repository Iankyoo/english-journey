# 05 — Substantivos contáveis e incontáveis

> Aula curta e de altíssimo retorno. *"Thanks for the **feedbacks**"* e
> *"I need more **informations**"* são duas das frases mais comuns de brasileiro
> em ambiente de trabalho — e as duas estão erradas.

**Módulo:** 1A · **Sessões:** 1 · **Anterior:** [04 — Artigos](../04-articles/) · **Próxima:** [06 — Quantificadores](../06-quantifiers/)

---

## 1. A ideia em uma frase

Incontável = o inglês trata como **massa**, não como unidades — logo **nunca tem plural**
e **nunca leva `a/an`**.

---

## 2. Forma

| | Contável | Incontável |
|---|----------|------------|
| Plural | bug → bug**s** | information → *~~informations~~* |
| Artigo `a/an` | **a** bug | *~~an information~~* |
| Verbo | The bugs **are** open | The information **is** correct |
| Quantificador | **many** / **few** bugs | **much** / **little** information |
| Pergunta | **How many** bugs? | **How much** time? |

---

## 3. Uso

### 3.1 A lista que resolve o seu dia a dia

Todos estes são **incontáveis em inglês** e contáveis em português — por isso o erro:

| 🚫 Não existe | ✅ Forma correta |
|--------------|-----------------|
| *informations* | **information** |
| *advices* | **advice** |
| *feedbacks* | **feedback** |
| *knowledges* | **knowledge** |
| *researches* | **research** |
| *softwares* / *hardwares* | **software** / **hardware** |
| *equipments* | **equipment** |
| *furnitures* | **furniture** |
| *luggages* | **luggage** |
| *works* (= trabalho) | **work** |
| *homeworks* | **homework** |
| *progresses* | **progress** |
| *traffics* | **traffic** |
| *evidences* | **evidence** |
| *moneys* | **money** |
| *staffs* (= equipe) | **staff** |
| *trainings* | **training** |

### 3.2 Como contar um incontável

Use um **contêiner**:

```
a piece of advice          →  three pieces of advice
a piece of information     →  two pieces of information
a bit of feedback
a piece of equipment
an item of furniture
a cup of coffee
```

Ou reformule para o adjetivo:

```
❌ Thanks for the feedbacks.
✅ Thanks for the feedback.          ← simplesmente sem "s"
✅ Thanks for all your feedback.
✅ Thanks for your comments.         ← "comments" É contável
```

### 3.3 As armadilhas de concordância

| Palavra | Regra | Exemplo |
|---------|-------|---------|
| **news** | parece plural, é **singular** | The news **is** good. |
| **people** | parece singular, é **plural** | People **are** waiting. |
| **data** | tecnicamente plural; hoje aceito como singular | The data **is** ready. *(informal, dominante em tech)* |
| **staff / team** | singular (US) / pode ser plural (UK) | The team **is** working on it. |
| **everyone / everybody** | **singular** | Everyone **is** here. |

### 3.4 Palavras que mudam de sentido

Alguns incontáveis viram contáveis com **outro significado**:

| Incontável | Contável |
|-----------|----------|
| **coffee** (a bebida) | **a coffee** (uma xícara) |
| **experience** (vivência) | **an experience** (um episódio) |
| **time** (tempo) | **a time** (uma vez / época) |
| **paper** (papel) | **a paper** (um artigo) |
| **room** (espaço) | **a room** (um cômodo) |
| **work** (trabalho) | **a work** (uma obra de arte) |

```
I don't have much experience with Kubernetes.   ← vivência
That was a great experience.                    ← episódio
We don't have enough room for another service.  ← espaço
```

## 4. 🇧🇷 Erros de brasileiro

| ❌ | ✅ | Por quê |
|----|----|---------|
| *I need more informations.* | more **information** | Incontável não pluraliza |
| *Thanks for the feedbacks.* | the **feedback** | Idem |
| *He gave me a good advice.* | **a piece of** good advice / **some** good advice | Não leva `a` |
| *The news are bad.* | The news **is** bad. | `news` é singular |
| *The people is waiting.* | People **are** waiting. | `people` é plural |
| *We use many softwares.* | a lot of **software** / many **tools** | Incontável |
| *How many time?* | **How much** time? | Incontável usa `much` |
| *I have many works to do.* | a lot of **work** | `work` = incontável |
| *Everyone are ready.* | Everyone **is** ready. | Singular |

> 💼 Estes erros aparecem em **e-mail e code review** — o lugar onde mais gente te lê.
> Peso alto por unidade.

## 5. ✍️ Prática

**A. Corrija (10 frases erradas).**
1. Can you send me more informations?
2. Thanks for all the feedbacks on my PR.
3. He gave me a very good advice.
4. The news about the layoff are terrible.
5. The people in this team is great.
6. We need to buy new equipments.
7. How many time do we have?
8. I made a lot of progresses this week.
9. Everyone are waiting for the deploy.
10. We use many softwares for monitoring.

**B. Escreva 5 frases** usando `information`, `advice`, `feedback`, `research` e `work` —
todas no singular, todas com quantificador correto (`some`, `much`, `a piece of`, `a lot of`).

**C. Releia seus últimos 3 daily logs** procurando plurais indevidos. Todo achado vai
para o [error-log.md](../../../error-log.md) com categoria `grammar`.
