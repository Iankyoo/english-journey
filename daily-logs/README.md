# 📓 Daily Logs

Mini projeto do **Módulo 1A** — 10 linhas por dia durante 14 dias.

## Regras

1. Escreve **primeiro**, sem dicionário. Trava numa palavra? Escreve em português entre `[colchetes]` e segue.
2. Só depois de fechar o texto: dicionário, revisão, correção.
3. A versão original **não se apaga**. O valor está na diferença entre as duas.
4. Todo erro corrigido vira linha no [error-log.md](../error-log.md).

## Nomenclatura

`YYYY-MM-DD.md` — ex: `2026-08-11.md`

## Template

Copie [`_TEMPLATE.md`](_TEMPLATE.md) para cada dia novo.
