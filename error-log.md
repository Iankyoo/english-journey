# 🩹 Error Log

> Todo erro corrigido vem parar aqui. Sem exceção.
> A regra não é registrar o erro — é registrar **por que** ele acontece.

## Como usar

1. Errou (texto, fala, exercício, correção de tutor)? Adiciona uma linha.
2. Preenche a coluna **Padrão** — a causa real, não o sintoma.
3. Toda sexta: releia a tabela inteira. Erro que aparece 3x vira card no Anki.
4. Erro que ficou 4 semanas sem reaparecer → move para [Erros Superados](#-erros-superados).

**Categorias:** `grammar` · `vocab` · `preposition` · `article` · `word-order` · `collocation` · `spelling` · `pronunciation` · `register` · `false-friend`

## 🪤 Falsos cognatos PT → EN

| Português | ❌ Parece | ✅ É | Nota |
|-----------|----------|------|------|
| pretender | *pretend* | **intend** | `pretend` = fingir |
| atualmente | *actually* | **currently** | `actually` = na verdade |
| eventualmente | *eventually* | **occasionally** | `eventually` = no fim das contas |
| pular | *pull* | **skip / jump** | — |
| notícia | *notice* | **news** | `notice` = aviso / perceber |
| resumir | *resume* | **summarize** | `resume` = retomar |
| suportar (tolerar) | *support* | **put up with** | `support` = apoiar |
| assistir (ver) | *assist* | **watch** | `assist` = auxiliar |
