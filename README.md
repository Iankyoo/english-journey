## 📌 Regras da Jornada

1. **Todo dia**, mesmo que 15 minutos. Consistência > intensidade.
2. Todo erro corrigido vai para o [`error-log.md`](error-log.md).
3. Nunca marcar checkbox por reconhecer — só por conseguir **produzir**.
4. Anki é inegociável: 20min/dia.
5. Um módulo só fecha quando o mini projeto estiver feito.
6. O repositório é público de propósito. Sem apagar erro feio.
