## Regras

1. **Auto-revisão antes de pedir correção.** Sempre.
2. Toda correção recebida → [error-log.md](../error-log.md).
3. Guardar a versão original junto da corrigida. O diff é o aprendizado.
4. Cada texto declara no topo quais **3 estruturas novas** está tentando aplicar.
